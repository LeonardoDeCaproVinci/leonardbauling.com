Platform Product 01

Orbitra Identity

Headless identity service

Orbitra Identity is the bouncer, concierge, and backstage pass system rolled into one. It is built to issue clean application-aware access, carry instance context with the token, and stay out of the user's way once trust has been established. The goal is not "identity as ceremony"; it is identity as a quiet but sharp control plane.

What it does

  • Authenticates users and issues JWTs with application and instance-aware claims.
  • Supports admin-managed user creation and application-instance access assignment.
  • Acts as the trust seam for downstream products like Orbitra Ledger.

Product shape

Identity is now a supporting platform seam rather than something this page needs to expose through operator shortcuts. The value is in the clean access model, application-instance context, and reuse across products, not in asking a reader to click health checks.

Platform Product 02

Orbitra Ledger

Browser app + API

Orbitra Ledger is where the numbers stop pretending to be neutral and start becoming usable. It is being shaped as a money workflow product that helps budgets, categories, transactions, periods, and workspaces feel connected rather than scattered. The mood is less "enterprise accounting bunker" and more "calm command deck with receipts."

What it does

  • Uses Identity-issued tokens to scope access to the correct ledger instance.
  • Exposes API-backed workspace, account, category, period, budget, and transaction workflows.
  • Now includes a Hostinger-hosted Vue browser app running on the Orbitra platform host.
